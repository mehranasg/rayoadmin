# آزمون‌ها

هر فایل `qa_template_<ماژول>.js` هستهٔ همان ماژول در `app/core/js` (و در صورت نیاز صفحه‌اش در `app/js/pages`) را در Node بارگذاری و روی دادهٔ ساختگی آزمایش می‌کند. به اینترنت، سرور یا دادهٔ زنده نیازی ندارد.

```bash
# از ریشهٔ مخزن
for f in tests/qa_template_*.js; do node "$f" || echo "FAIL $f"; done
```

هر فایل در پایان `<نام>: N passed, M failed` چاپ می‌کند و اگر خطا داشته باشد با کد ۱ خارج می‌شود.

- `fixtures/`: فایل‌های نمونهٔ ورود تردد (حضور و غیاب).
- آزمون تازه: کنار آزمون همان ماژول اضافه شود. دادهٔ واقعی و رمز در آزمون نیاید.
