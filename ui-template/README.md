# Rayo UI Template

قالب مستقل طراحی برای پنل مدیریت رایو. **به برنامهٔ اصلی وصل نیست**: هیچ فایل، API یا دادهٔ واقعی‌ای را بارگذاری نمی‌کند و همهٔ اعداد نمونه هستند (`js/mock-data.js`).

## اجرا

کافی است `index.html` را در مرورگر باز کنید یا پوشه را با یک سرور ساده اجرا کنید:

```
npx serve ui-template
```

## صفحه‌ها

| صفحه | محتوا |
|---|---|
| `index.html` | داشبورد: KPI با sparkline، روند فروش، سهم دسته‌ها، نقشهٔ حرارتی ساعات اوج، پرفروش‌ها، گزارش صندوق، هشدارها |
| `reports.html` | سود و زیان (ستون انباشته + حاشیه سود، آبشاری)، ماتریس مهندسی منو، treemap خرید، مغایرت مصرف، رضایت مشتری (gauge و radar) |
| `inventory.html` | ساختار ۱۰ تب انبار، جدول موجودی با فیلتر، فرم رسید، سفارش مجدد، مودال |
| `components.html` | مرجع توکن‌ها و کامپوننت‌ها |

## ساختار

- `css/theme.css` — تمام توکن‌ها (`:root`) و کامپوننت‌ها، تم روشن/تیره.
- `js/app.js` — سایدبار، تاپ‌بار، تغییر تم، فرمت اعداد فارسی/تاریخ شمسی، helper نمودار (`RT.chart`).
- `js/*.js` — منطق نمایشی هر صفحه.

## وابستگی‌ها (CDN)

- [Apache ECharts 5.5.1](https://echarts.apache.org) — نمودارها (رندر SVG)
- [Lucide 0.460.0](https://lucide.dev) — آیکون‌ها
- فونت: `IRANSansX` اگر روی سیستم نصب باشد، وگرنه Vazirmatn از Google Fonts

برای استفاده در برنامهٔ اصلی بهتر است این کتابخانه‌ها و فونت IRANSansX به‌صورت محلی (vendor) قرار بگیرند.

## پیاده‌سازی روی برنامهٔ اصلی (بعدی)

1. توکن‌های `:root` به `css/style.css` منتقل شوند و رنگ‌های ثابت با متغیر جایگزین شوند.
2. کلاس‌های فعلی (`.btn`، `.card`، `.table`، `.tabs` …) به ظاهر این قالب نگاشت شوند؛ HTML و منطق تغییر نمی‌کند.
3. استایل‌ها و رنگ‌های inline در JS به کلاس/متغیر تبدیل شوند.
4. نمودارها در فاز جدا با ECharts جایگزین شوند.
