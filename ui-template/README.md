# Rayo UI Template

قالب مستقل طراحی برای پنل مدیریت رایو. **به برنامهٔ اصلی وصل نیست**: هیچ فایل، API یا دادهٔ واقعی‌ای را بارگذاری نمی‌کند و همهٔ اعداد نمونه هستند (`js/mock-data.js`).

## اجرا

کافی است `index.html` را در مرورگر باز کنید یا پوشه را با یک سرور ساده اجرا کنید:

```
npx serve ui-template
```

## صفحه‌ها

| صفحه | محتوا |
|---|---|
| `index.html` | داشبورد: KPI با sparkline، روند فروش، سهم دسته‌ها، نقشهٔ حرارتی ساعات اوج، پرفروش‌ها، گزارش صندوق، هشدارها |
| `reports.html` | سود و زیان (ستون انباشته + حاشیه سود، آبشاری)، ماتریس مهندسی منو، treemap خرید، مغایرت مصرف، رضایت مشتری (gauge و radar) |
| `inventory.html` | ساختار ۱۰ تب انبار، جدول موجودی با فیلتر، فرم رسید، سفارش مجدد، مودال |
| `inventory-control.html` | کنترل انبار و مغایرت **با دادهٔ واقعی و فقط خواندنی** (`js/inventory-engine.js` + `js/inventory-control.js`): داشبورد، گزارش ماهانه/بازه‌ای (از ابتدای «از تاریخ» تا انتهای «تا تاریخ»)، گردش مواد مقداری و ریالی با CSV، «کجا دنبال مغایرت بگردم» (ایراد داده، جفت کسری/مازاد، مغایرت بی‌توضیح)، پرتی با روند و مسئولیت، نوشیدنی، «روغن و اقلام سر میز» (دفتر تعویض روغن سرخ‌کن با گنجایش هر سرخ‌کن، کسری انبار روغن = اول + ورود − ریخته‌شده − پایان، برآورد گرم روغن هر رسپی از روغن ریخته‌شده به نسبت فروش × وزن نسبی؛ اقلام سر میز مثل روغن زیتون و سس‌ها: مصرف خارج از رسپی، نسبت به ۱۰۰ آیتم فروش/فیش سالن، ثبت معیار و اختلاف با معیار — این ثبت‌ها در قالب فقط در localStorage مرورگر است)، انبارگردانی‌ها، ورود، فروش و خروجی AI. فقط `GET RayoData/Load` صدا زده می‌شود (هیچ Save)؛ اتصال زنده فقط از دامنهٔ rayocafe.ir (CORS)، در غیر این صورت فایل‌های JSON انبار و قیمت‌گذاری انتخاب می‌شوند (یا `?data=<پوشه>/` با `inventory.json` و `pricing.json`). دادهٔ زنده در مخزن ذخیره نشود. |
| `petty-cash.html` | **طرح** مدیریت تنخواه (دادهٔ نمونه، `js/petty-cash.js`): کارت‌های تنخواه پرسنل، ثبت هزینه از گوشی با عکس رسید و علت خرید، کنترل خودکار (رسید، علت، سقف هر خرید و بودجهٔ دسته، قیمت مرجع، پذیرندهٔ نامرتبط/شخصی، ساعت کاری، خرید خُردشده، تکراری، مبلغ رُند، قلم انبار)، ورود صورتحساب کارت و تراکنش اعلام‌نشده، تصمیم مدیر (تأیید/شخصی — کسر از حقوق/رد)، تسویهٔ ماهانه و ساختار دادهٔ پیشنهادی. هنوز به پنل وصل نیست. |
| `invoice-ai.html` | **طرح** ثبت فاکتور خرید با عکس و AI (`js/invoice-ai.js`؛ استخراج شبیه‌سازی می‌شود): عکس با دوربین گوشی ← سرور رایو ← Claude (`claude-opus-5-5`، خروجی ساختاریافته با JSON Schema) ← پیش‌نویس با تطبیق تأمین‌کننده/کاتالوگ، تبدیل ریال و واحد، کنترل جمع، قیمت در برابر آخرین خرید و اطمینان هر ردیف ← تأیید مدیر ← فاکتور نهایی (و ورود به انبار). کلید API فقط روی سرور. |
| `components.html` | مرجع توکن‌ها و کامپوننت‌ها |
| `blueprint.html` | طرح پیشنهادی محصول (نه وضعیت فعلی): نقشهٔ ۶ حوزه و ۲۸ ماژول، اصول ساده‌سازی، فازبندی، مقایسه با بازار و نمونهٔ صفحه‌های میز کار، صندوق/KDS، مشتریان و باشگاه، دریافت کالا با تطبیق فاکتور، موجودی، چرخهٔ ماه پرسنل، طرف حساب‌ها، بستن ماه و سود و زیان (مسیر با `#`، مثلاً `blueprint.html#crm`) |
| `panel/index.html` | **نمونهٔ کامل استاتیک طرح جدید** (۷ بخش: میز کار، مالی، انبار، پرسنل، منو و قیمت، گزارش‌ها، تنظیمات + طرح جامع). دفتر واحد طرف حساب و فرم واحد پرداخت، پروندهٔ ماهانهٔ پرسنل، نمای هر نقش، خروجی AI. فقط دادهٔ ساختگی؛ جزئیات در `panel/README.md` |

## ساختار

- `css/theme.css` — تمام توکن‌ها (`:root`) و کامپوننت‌ها، تم روشن/تیره.
- `js/app.js` — سایدبار، تاپ‌بار، تغییر تم، فرمت اعداد فارسی/تاریخ شمسی، helper نمودار (`RT.chart`).
- `js/*.js` — منطق نمایشی هر صفحه.

## وابستگی‌ها (CDN)

- [Apache ECharts 5.5.1](https://echarts.apache.org) — نمودارها (رندر SVG)
- [Lucide 0.460.0](https://lucide.dev) — آیکون‌ها
- فونت: `IRANSansX` اگر روی سیستم نصب باشد، وگرنه Vazirmatn از Google Fonts

برای استفاده در برنامهٔ اصلی بهتر است این کتابخانه‌ها و فونت IRANSansX به‌صورت محلی (vendor) قرار بگیرند.

## پیاده‌سازی روی برنامهٔ اصلی (بعدی)

1. توکن‌های `:root` به `css/style.css` منتقل شوند و رنگ‌های ثابت با متغیر جایگزین شوند.
2. کلاس‌های فعلی (`.btn`، `.card`، `.table`، `.tabs` …) به ظاهر این قالب نگاشت شوند؛ HTML و منطق تغییر نمی‌کند.
3. استایل‌ها و رنگ‌های inline در JS به کلاس/متغیر تبدیل شوند.
4. نمودارها در فاز جدا با ECharts جایگزین شوند.
