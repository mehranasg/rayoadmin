# رایو — نرم‌افزار مدیریت کافه‌رستوران

نرم‌افزار مدیریت کافه‌رستوران رایو. روی دادهٔ واقعی کار می‌کند و مبنای یک محصول جامع برای کافه‌رستوران‌های دیگر است (طرح توسعه در `docs/ROADMAP.md`).

| پوشه | چیست |
|---|---|
| [`app/`](app/) | اپ مدیریت: مالی، انبار، پرسنل و حقوق، منو و بهای تمام‌شده، گزارش‌ها، تنظیمات. برای انتشار، همین پوشه آپلود می‌شود ([راهنما](app/README.md)) |
| [`tests/`](tests/) | آزمون‌های هستهٔ اپ ([اجرا](tests/README.md)) |
| [`docs/`](docs/) | مستندات ([فهرست](docs/README.md)): وضعیت فعلی، معماری، طرح توسعه، بک‌لاگ، تصمیم‌ها، طرح جامع |
| [`legacy/`](legacy/) | پنل قدیمی، منجمد ([چرا هنوز هست](legacy/README.md)) |

دستیار هوش مصنوعی: [CLAUDE.md](CLAUDE.md). ثبت ایده یا کار، بدون اجرا: پیام را با «ثبت کن:» شروع کنید (جزئیات در CLAUDE.md).
