# مسیر سازگار تحویل پروژه v10.12.1

این مسیر برای سازگاری با AGENTS و ارجاع‌های قدیمی حفظ شده است. محتوای قبلی پس از بررسی سورس و اعتبارسنجی مراجع جدید در پالایش 2026-09-19 تفکیک شد؛ نسخهٔ کامل پیشین در Git و Backup خارجی محفوظ است. این فایل سند تاریخی مفصل یا مرجع مستقل جدید نیست.

شروع: [AI_START_HERE](AI_START_HERE.md). برای تغییر معماری، [مشخصات محصول](PROJECT_MASTER_SPEC.md)، [پیاده‌سازی فعلی](CURRENT_IMPLEMENTATION.md)، [قرارداد داده/API](DATA_AND_API_REFERENCE.md) و مسیر مربوط از [راهنمای بازسازی و مهاجرت](REBUILD_AND_MIGRATION_GUIDE.md) را بخوانید. برای تشخیص سریع، [ماتریس قابلیت‌ها](FEATURE_STATUS_MATRIX.md) مرجع است.

برنامهٔ جاری MPA است؛ React و دیتابیس طرح آینده‌اند. Backend مرجع C# در مخزن وجود دارد ولی پروژهٔ میزبان و وضعیت استقرار آن تأیید نشده است. Load عادی نباید Seed یا Save عملیاتی ایجاد کند؛ کاتالوگ اصلی pricing.ingredients و انبار دارای ۹ تب است. تمام قواعد قبلی AGENTS همچنان معتبرند.

جزئیات Backup، hash، فایل‌های ادغام‌شده و نتیجهٔ QA: [گزارش پالایش](DOCS_CLEANUP_REPORT.md). تاریخچه را فقط برای نیاز مشخص بخوانید؛ [سیاست مستندات](DOCUMENTATION_POLICY.md).
