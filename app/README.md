# اپ مدیریت رایو

پنل مدیریت (`index.html`)، اپ پرسنل (`staff.html`) و دموی صندوق، سفارش‌گیر، آشپزخانه و طرح پنل پرسنل (`staffdemo.html`). صفحهٔ ایستاست و build ندارد. توضیح کامل در [docs/STATE.md](../docs/STATE.md) و [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) است.

## آپلود روی سرور
1. **کل محتوای همین پوشهٔ `app/`** را در پوشهٔ مقصد سرور آپلود کنید. الان مقصد `rayocafe.ir/newpanel/` است؛ هر مسیر دیگری هم کار می‌کند.
2. ساختار داخلی را نگه دارید: `index.html`، `core/`، `css/`، `js/`، `skins/`، `vendor/` (کتابخانهٔ نمودار، آیکون و Excel؛ بدون آن نمودارها روی شبکه‌هایی که CDN بسته است نمایش داده نمی‌شوند) و صفحه‌های `staff.html` و `pos/waiter/kds/staffdemo.html` کنار هم بمانند. لینک اپ پرسنل برای پرسنل: `<مسیر آپلود>/staff.html` (مثلاً `rayocafe.ir/newpanel/staff.html`).
3. فایل‌های قدیمی مقصد را پاک نکنید؛ همه با همان نام جایگزین می‌شوند. فایل‌هایی که از اپ حذف شده‌اند فقط مانده‌اند و اثری ندارند.
4. بعد از آپلود، صفحه را با Ctrl+F5 باز کنید تا نسخهٔ تازه بارگذاری شود.

اپ به API ‏RayoData وصل می‌شود (`core/js/inventory-engine.js` ← `API_ROOT`). لینک‌های «در پنل فعلی» به `/panel/` می‌روند. مسیر دیگر با `window.RAYO_CURRENT_PANEL` قبل از بارگذاری `js/shell.js` تعیین می‌شود.

## اجرای محلی
`index.html` را در مرورگر باز کنید. بدون اتصال، بخش‌ها دادهٔ نمونه نشان می‌دهند. با `index.html?data=<پوشهٔ JSON>/` فایل‌های JSON ماژول‌ها از آن پوشه خوانده می‌شوند.
