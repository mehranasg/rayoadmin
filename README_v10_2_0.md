# Rayo Admin v10.2.1

Operational closeout release based on v10.1.0.

- ثبت فروش Snapp و اثر مستقیم روی موجودی
- ناوبری ساده Inventory با یک Sidebar link و Tabهای داخلی
- ارزش روز موجودی مواد
- شمارش اولیه با آخرین قیمت خرید
- اصلاح Material dropdown در روند مغایرت
- حذف پرداخت تأمین‌کننده از Inventory
- Cost Forecast در Reports
- Personnel status = اتمام همکاری و فیلتر پیش‌فرض فعال
- Staff cash date/duplicate guards
- Mobile modal/layout fixes
- Money thousand separator
- Per-module reset
- Popups only close via explicit controls
